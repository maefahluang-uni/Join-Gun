# JoinGun — HTML Prototype

ต้นแบบ core workflow **เข้าร่วมกิจกรรมจากฟีด** สำหรับนักศึกษาที่เข้าสู่ระบบและยืนยันอีเมลแล้ว ใช้ HTML, CSS และ JavaScript ธรรมดา ไม่มี framework หรือขั้นตอนติดตั้ง dependency

## เปิดใช้งาน

ดาวน์โหลดหรือ clone repo แล้วเปิด [prototype/index.html](prototype/index.html) ใน Chrome, Edge หรือ Firefox รุ่นปัจจุบัน โดยเก็บ [styles.css](prototype/styles.css) และ [app.js](prototype/app.js) ไว้ในโฟลเดอร์เดียวกัน เปิดผ่าน `file://` ได้ ไม่ต้องมี backend

GitHub แสดงไฟล์ HTML เป็น source code หากต้องการทดลองกดให้เปิดไฟล์ที่ดาวน์โหลดมาบนเครื่อง การ push repo ครั้งนี้ไม่ได้เปิดใช้ GitHub Pages

## หน้าจอและขั้นตอนทดลอง

| Journey | หน้าจอ / การกระทำ | ผลที่คาดหวัง |
| --- | --- | --- |
| 1 | หน้ากิจกรรม `#feed` | เห็นกิจกรรมตัวอย่าง 4 รายการ พร้อมวันเวลา สถานที่ และจำนวนคน |
| 2 | กด “ตัวกรอง” เลือก “กีฬา” และวันที่ 9 ก.ย. 2569 แล้วกด “แสดงกิจกรรม” | เหลือกิจกรรม “ตีแบดหลังเลิกเรียน”; ค้นหาด้วยชื่อหรือสถานที่ได้ด้วย |
| 3 | กด “ดูรายละเอียด” | เห็นรายละเอียด ผู้จัดตัวอย่าง จุดนัดหมายจำลอง และปุ่ม “เข้าร่วมกิจกรรม” |
| 4 | กด “เข้าร่วมกิจกรรม” อ่านนโยบาย แล้วเลือก checkbox ความยินยอมและกด “ยืนยันเข้าร่วม” | ปุ่มยืนยันใช้ไม่ได้ก่อนให้ความยินยอม; เมื่อกดแล้วแสดงกำลังเข้าร่วมและป้องกันการกดซ้ำ |
| 5 | หน้าผลสำเร็จ `#success/badminton` แล้วกด “ดูรายละเอียดกิจกรรม” | แสดง “เข้าร่วมแล้ว” จำนวนเพิ่มจาก 4/8 เป็น 5/8 และไม่มีปุ่มเข้าร่วมซ้ำ |

มี 3 หน้าหลัก (ฟีด รายละเอียด ผลสำเร็จ) และ 2 dialog (ตัวกรอง ยืนยัน) ใช้ hash navigation เพื่อรองรับปุ่มย้อนกลับของเบราว์เซอร์

เพิ่มเติม: ทดลองวันที่ที่ไม่มีกิจกรรมเพื่อดู empty state และกด “ล้างตัวกรอง”; ปิดแผงยืนยันหรือกด Escape ก่อนส่งจะไม่เข้าร่วม; เข้าร่วมกิจกรรมที่สองจะแสดงความยินยอมที่ให้ไว้แล้วและปุ่ม “จัดการความยินยอม” เพื่อเลือกใหม่ รีเฟรชหน้าเพื่อล้างข้อมูลทดลองทั้งหมด

## ขอบเขตและข้อจำกัด

- ใช้ข้อมูลกิจกรรม ผู้จัด และสถานที่สมมติสำหรับสาธิต วันที่ตัวอย่าง 9–11 ก.ย. 2569 แสดงเวลา Asia/Bangkok ไม่ใช่กิจกรรมที่จองได้จริง
- แผนที่เป็น placeholder ระบุว่า “แผนที่จำลอง” พร้อมจุดนัดหมายเป็นข้อความ ไม่มีพิกัด GPS หรือบริการแผนที่ภายนอก
- การเข้าร่วม ความยินยอม และตัวกรองอยู่ในหน่วยความจำของหน้านี้เท่านั้น ไม่มี cookies, localStorage, analytics, network requests หรือการเก็บข้อมูลส่วนตัวจริง
- การยืนยันสำเร็จเป็นการจำลอง response ไม่ใช่ธุรกรรมบน server; ยังไม่มีระบบ email verification, access log, consent audit record, encryption, AI, notifications หรือฟีเจอร์นอก core workflow จึงยังไม่ใช่ระบบที่ผ่านข้อกำหนด backend/compliance/NFR
- ใช้ tokens จาก design-system, คอลัมน์เดียวสูงสุด 480px, controls ขั้นต่ำ 44–48px, native modal dialog, focus/keyboard support และ live status; ใช้ Noto Sans Thai ถ้ามีในเครื่อง มิฉะนั้นใช้ system font เพื่อให้เปิดได้โดยไม่ดาวน์โหลดฟอนต์
